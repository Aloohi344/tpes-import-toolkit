# Важная информация об импорте — ТПЭС

Telegram Mini App компании ООО «Трипиэль Сервис» (ТПЭС): калькулятор стоимости ввоза, разбор цены перевозки, документы, проверка поставщика и разбор ошибок.

Откройте приложение в Telegram или в браузере с этой страницы GitHub Pages.

## Калькулятор и ТН ВЭД

Справочник ставок — официальный Единый таможенный тариф ЕАЭС (файлы ЕЭК). При открытии калькулятора загружаются все 13 001 десятизначных кодов, с учётом действующих примечаний на дату выгрузки справочника. Антидемпинговые и специальные пошлины, акциз и тарифные преференции справочником не определяются. НДС 10% из перечня п. 2 ст. 164 НК РФ автоматически не определяется. Окончательные код ТН ВЭД и ставку подтверждает декларант.

Источник: [ЕТТ ЕАЭС на сайте ЕЭК](https://eec.eaeunion.org/comission/department/catr/ett/).
